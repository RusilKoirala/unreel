Install it in four easy steps

Unreel isn't on the Chrome Web Store yet, so you add it yourself. It takes about two minutes.

  1. Download Unreel

    You'll get one small file called unreel.zip.

    Download unreel.zip

  2. Unzip it

    Mac: double-click the zip.
    Windows: right-click it, then choose Extract All.

    Move the new unreel folder to Documents and keep it there. Unreel stops working if the folder is moved or deleted.

  3. Open Chrome's extensions page

    Copy this, paste it into the address bar and press Enter:

    chrome://extensions

    Then turn on Developer mode at the top right.

  4. Add the folder

    Click Load unpacked at the top left, then choose your unreel folder. Unreel is now on.

You're done

Open YouTube and the Shorts are gone.

To keep Unreel handy, click the puzzle piece next to the address bar, then the pin beside Unreel. Click its icon any time to see your screen time, change what's hidden or set limits.

If something goes wrong

Chrome says "Manifest file is missing"

You chose the wrong folder. Open the unreel folder and check that manifest.json sits directly inside it, then choose that exact folder. If you see the file called unreel.zip, unzip it first.

Developer mode is greyed out or missing

Your school or workplace probably manages this browser, and only its admin can allow this. Try Unreel on a personal Chrome profile or your own computer.

Unreel disappeared or shows an error

The folder was probably moved or deleted. Put it back in the same place and click the reload icon on Unreel's card. If you load it from a new place instead, Chrome treats it as a new extension, so you'll need to set your choices and hours again.

A hidden thing has come back

YouTube and Instagram change their pages often, which can break what Unreel hides. Check for a newer version, or report it on GitHub.

Why is my screen time different from my phone's?

Unreel only counts YouTube and Instagram in this Chrome, while they're on your screen. It stops counting after a minute with no activity, unless a video is playing.

How do I update Unreel?

Chrome can't update it for you while it's installed this way. Download the new zip, replace everything in your unreel folder with the new files, then click the reload icon on Unreel's card in chrome://extensions. See all versions.

Is it safe to install this way?

Developer mode lets Chrome run extensions that didn't come from its store, so only load ones you trust. Unreel has no account, runs only on YouTube and Instagram, and sends nothing anywhere, including your screen time. All the code is public, and so is the privacy policy.

How do I remove it?

Click Remove on Unreel's card in chrome://extensions, then delete the folder.
